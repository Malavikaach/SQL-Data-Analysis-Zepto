# Zepto SQL Data Analysis Project

## Project Overview
This project analyzes Zepto product data using PostgreSQL SQL queries.

## Database Table
The project creates a table named `zepto` containing:

- SKU ID
- Category
- Product Name
- MRP
- Discount Percentage
- Quantity
- Weight
- Stock Status

## SQL Operations Performed

1. Data Exploration
   - Count rows
   - Check null values
   - View sample data

2. Data Cleaning
   - Remove zero-price products
   - Convert paisa to rupees

3. Analysis
   - Product categories
   - Stock availability
   - Highest discounts
   - Revenue estimation
   - High MRP products out of stock
   - Average discounts
   - Price per gram analysis

## Technologies Used
- PostgreSQL
- pgAdmin
- SQL

## Key Insights
- Identified highest discount products
- Estimated category-wise revenue
- Found out-of-stock expensive products
- Compared value based on price per gram
